# PlayHandoff product demo

Public page: https://williamlovecs.github.io/playhandoff-demo/

117-second English-captioned demonstration of an earlier working local prototype. The coach writes a Final, the athlete records version-specific receipts, and Actual is self-reported. All athlete data is synthetic adult test data. This is not a production SaaS, customer evidence, medical advice, autonomous AI prescription or proof of time savings.

## Media versions

- `assets/demo-narrated-20261118.mp4`: the page's narrated version. The original H.264 video and burned captions are preserved; one English AAC narration track is added. Standard synthetic voice, not a clone of the founder or another real person. No music.
- `assets/demo-silent-20261117.mp4`: versioned silent rollback copy.
- `assets/demo.mp4`: original silent URL, intentionally unchanged for existing consumers, including the separate marketing website.
- `assets/poster.jpg`: existing poster, unchanged.

English speech is generated locally with the official Qwen3-TTS Aiden voice. Model: https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice (Apache-2.0), revision `0c0e3051f131929182e2c023b9537f8b1c68adfe`. Model weights, development tools, private product code and internal records are not distributed in this repository.

Only static page files and approved demo media are published. No login, analytics, lead form, credentials, personal datasets or private source code. Native video controls and `playsinline` are enabled. The on-screen captions are part of the unchanged source video.

To roll back the public page, restore the prior page commit or point its video source at the versioned silent copy. No product repository or database change is required.
